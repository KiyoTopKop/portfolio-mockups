Building it, then breaking it

AutoShop Inventory & POS replaced a parts shop's Excel sheets. Before it went live, its only developer tried to break in.

Role: sole developer · Next.js 14 · TypeScript · Supabase · Playwright

The problem

A multi-branch auto parts shop tracked its stock and sales in Excel. The sheets drifted apart, so no one could say for certain which branch held what.

The approach

I rebuilt the system as a web app with four roles, enforced inside the database with Row Level Security rather than only in the interface. Barcode stock-in and stock-out, branch-to-branch transfers with approvals, and an audit log came next.

“Then I logged in as a staff account and tried to make myself an admin.”

The result

The Excel workflow is gone. The audit closed security and data-loss defects before launch, including a privilege-escalation path, and each fix is now guarded by an adversarial test.
